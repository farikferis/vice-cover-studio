Vice Cover Studio turns your photos and a caption into GTA-poster-style cover art: multi-panel layouts (Trio, Hero + strip, Quad), a Vice City sunset, neon or noir colour grade, bold outlined caption lettering, and PNG export in the three common post sizes — 1080 x 1080, 1080 x 1350 and 1920 x 1080. Built for make.fun's "Make GTA 6 Cover Art" bounty, $250 in USDC. An original design: no Rockstar logo, artwork or font.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```

1. Load 1–3 photos (file picker or drag-drop) or try the bundled samples.
2. Pick a layout, type a title and subtitle, choose a grade.
3. Click a panel to select it, drag inside it to move its photo, use Zoom to crop.
4. Pick an export size and hit **Export PNG**.

The app is plain static files under `app/` — no build step, no network requests, photos never leave your machine.
